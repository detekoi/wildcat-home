The platform

Wildcat is a set of bot tools for Twitch and YouTube streams. Sage answers questions in chat, WildcatTTS reads messages aloud in natural voices, and the chat overlay generates a theme that matches your stream. Each tool needs little setup.

The three tools are built and maintained together as one platform. Wildcat is in invite-only beta. To join, request access.
