Twitch Scheduler is a personal tool for one Twitch streamer. It runs on the computer of the streamer. It is not a public service, and nobody else can sign in to it.

## What it does

- It adds the streams for the next week to the Twitch schedule.
- If an event on the Google Calendar of the streamer overlaps a stream, it skips that stream.
- It sends an email to the streamer to ask which game to play each day, and it reads the reply.
- It adds each stream to a separate calendar named Streams in Google Calendar.
- After the streamer approves the week, it posts the schedule to the Discord server of the streamer.

The [privacy policy](/twitch-scheduler/privacy/) tells which Google data the tool uses and why.
