Twitch Scheduler is a personal tool. It runs on one computer and has one user, the streamer who owns it. This policy tells which Google user data the tool uses, why it uses that data, and where it keeps the data.

## Google data that the tool uses

| Permission | What the tool does with it |
| --- | --- |
| See your calendar events | The tool reads the times of events on your primary calendar. If an event overlaps a stream, the tool removes or skips that stream. It reads the event name only to put it in the email to you. |
| Make secondary calendars | The tool makes one calendar named Streams. It adds, changes, and deletes stream events on that calendar only. |
| Send email for you | The tool sends the schedule email from your account to your own address. |
| Read, compose, and send email, and change labels | The tool reads the replies in the schedule email thread that it started. After it reads a reply, it takes that reply out of your inbox and marks it read. It does not use or change other email. |
| See your email address | The tool uses your address to send the email and to make sure that a reply came from you. |

## Where the data goes

The tool keeps its sign-in tokens and its schedule notes in files on your computer. It does not send these files to a server.

To read a reply, the tool sends the reply text to the Google Gemini API. Gemini turns the reply into a list of games. The tool sends the stream times and games to Twitch and to Discord. It does not send calendar event names to Twitch or to Discord.

The tool does not sell Google user data. It does not use the data for ads, and it does not give the data to other people.

## Limited Use

Twitch Scheduler receives information from Google APIs. Its use and transfer of that information follows the [Google API Services User Data Policy](https://developers.google.com/terms/api-services-user-data-policy), including the Limited Use requirements.

## Remove access

To stop the access of the tool, open [myaccount.google.com/connections](https://myaccount.google.com/connections). Then remove Twitch Scheduler from the list. To remove the saved data, delete the token file and the state file on your computer.

## Changes

If this policy changes, the date at the top of the page changes.
